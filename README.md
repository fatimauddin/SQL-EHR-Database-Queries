# EHR Database Restoration and SQL Analysis

## Project overview
Restored an Electronic Health Record (EHR) database in Microsoft SQL Server and used SQL queries to retreive, filter, join, and analyze patient and hospital encounter data. 

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

 ## Skills Demonstrated
- Restoring a SQL Server database from a backup file
- Retrieving patient demographic information
- Filtering and sorting data using WHERE and ORDER BY
- Combining tables using JOIN
- Identifying primary diagnosis codes
- Using DISTINCT, BETWEEN, and LIKE
- Calculating statistics using COUNT, AVG, MIN, and MAX
- Using column aliases to improve readability

  ## Project Tasks
1. Restored an existing EHR database.
2. Retrieved patient demographic information.
3. Identified primary diagnosis codes for patient encounters.
4. Filtered patient records by location.
5. Analyzed hospital lengths of stay and discharge codes.
6. Identified emergency department encounters.
7. Calculated encounter statistics.
8. Joined patient, encounter, and diagnosis tables to create
   a combined report.
